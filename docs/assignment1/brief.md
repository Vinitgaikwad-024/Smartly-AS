# Assignment 1 — Project brief
Smartly is a campus Access Flow Control Management System for classrooms, labs, and shared resources. Students search by building, room type, capacity, equipment, and time, then submit booking requests. Faculty review pending requests and approve or reject them. Administrators maintain rooms, buildings, and resources and monitor booking activity.

**Users:** students, faculty approvers, administrators.

**Nouns:** student, faculty member, administrator, building, room, resource, booking request, approval, availability, schedule.

**Verbs:** sign in, search, filter, view, request, approve, reject, cancel, manage, update, monitor.
